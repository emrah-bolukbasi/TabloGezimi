Navigation dans les tableaux 1.1.10

Prend en charge les tableaux Excel, du navigateur et des PDF ou documents accessibles.

Navigation dans les tableaux

Alt+Maj+O active ou désactive la navigation. Haut et Bas lisent toute la ligne; Gauche et Droite changent de cellule.

Alt+Maj+Haut : copier la ligne ; Bas : le tableau ; Gauche : la colonne ; Droite : la cellule.

Dans Excel, Alt+Maj+R lit la ligne actuelle. Les PDF numérisés nécessitent l’OCR.
