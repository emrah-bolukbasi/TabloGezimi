Table Navigation 1.1.10

Supports table navigation in Excel, web browsers and accessible PDF or document tables.

Usage

Toggle table navigation with Alt+Shift+O. Up and Down read an entire row with headings; Left and Right navigate cells.

Alt+Shift+Up: copy row; Alt+Shift+Down: copy table; Alt+Shift+Left: copy column; Alt+Shift+Right: copy cell.

Scanned image-only PDF tables require separate OCR.
