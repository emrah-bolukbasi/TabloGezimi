Table Navigation 1.1.11

Supports table navigation in Excel, web browsers and accessible PDF or document tables.

Usage

Toggle table navigation with Alt+Shift+O. Up and Down read an entire row with headings; Left and Right navigate cells.

Alt+Shift+Up: copy row; Alt+Shift+Down: copy table; Alt+Shift+Left: copy column; Alt+Shift+Right: copy cell.

Scanned image-only PDF tables require separate OCR.

What's new in 1.1.11

Ctrl+Shift+Alt+Up Arrow switches between row reading (mode 1) and single-cell reading (mode 2). Ctrl+Shift+Alt+Down Arrow opens a Turkish pause-time dialog (0–5000 ms, 150 ms default). These commands can be remapped in Input Gestures. The Alt+Shift+O enabled/disabled state is remembered between NVDA restarts; navigation mode resets to mode 1 when enabled. Excel arrow movement can leave data regions; empty destination cells announce their address. Bulk Excel reading/copying skips empty values and uses the active contiguous region.
