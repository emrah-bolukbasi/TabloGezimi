Навигация по таблицам 1.1.10

Поддерживает таблицы Excel, браузеров и доступных PDF-документов.

Навигация по таблицам

Alt+Shift+O включает или выключает режим. Вверх и вниз читают строку целиком, влево и вправо перемещаются между ячейками.

Alt+Shift+Вверх: копировать строку; Вниз: таблицу; Влево: столбец; Вправо: ячейку.

Для отсканированных PDF требуется OCR.
