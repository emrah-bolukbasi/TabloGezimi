يدعم الجداول في Excel والمتصفحات وملفات PDF والمستندات القابلة للوصول.

التنقل في الجداول

اضغط Alt+Shift+O للتفعيل أو الإيقاف. السهمان لأعلى ولأسفل يقرآن الصف كاملًا، واليمين واليسار للتنقل بين الخلايا.

Alt+Shift+أعلى لنسخ الصف، وأسفل للجدول، ويسار للعمود، ويمين للخلية.

تتطلب ملفات PDF الممسوحة ضوئيًا التعرف الضوئي على النص.
