# Table Navigation 1.1.10

A multilingual NVDA add-on for row-oriented accessible table navigation in Microsoft Excel, web pages, and accessible document/PDF readers.

Highlights:
- Read whole rows with column headings using Up/Down Arrow.
- Copy rows, columns, cells or entire tables.
- Includes Turkish, English, Spanish, Russian, Arabic, Simplified Chinese, German, French, and Italian.
- Removes the unused Alt+Shift+R command.

Requirements: Windows and NVDA 2026.1.0 or later, as declared by the add-on manifest. Some features are application-dependent; see README.md.
