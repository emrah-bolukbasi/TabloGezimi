# Tablo Gezimi – Türkçe kullanım

**Sürüm:** 1.1.10  
**Geliştirici:** Emrah Bölükbaşı

Tablo Gezimi, NVDA ekran okuyucusuyla Excel, internet sayfaları, HTML ve erişilebilir PDF/belge tablolarında satırları sütun başlıklarıyla birlikte okuyabilmek ve tablo verilerini kopyalamak için hazırlanmıştır.

## Kısayollar

| Kısayol | Görev |
| --- | --- |
| Alt + Shift + O | Tablo gezinmesini aç/kapat |
| Yukarı/Aşağı | Satır değiştir ve tüm satırı oku |
| Sol/Sağ | Hücre değiştir |
| Alt + Shift + Yukarı | Satırı kopyala |
| Alt + Shift + Aşağı | Tüm tabloyu kopyala |
| Alt + Shift + Sol | Sütunu kopyala |
| Alt + Shift + Sağ | Hücreyi kopyala |

Kopyalama komutları tablo gezinmesi açıkken kullanılır.

## Desteklenen diller

Türkçe, İngilizce, İspanyolca, Rusça, Arapça, Basitleştirilmiş Çince, Almanca, Fransızca ve İtalyanca. NVDA'nın arayüz dili desteklenmiyorsa İngilizce kullanılır.

## Sınırlar

Masaüstü Excel için Windows COM kullanılır. PDF okuyucusunun tabloyu NVDA'ya erişilebilir biçimde sunması gerekir. Resim olarak taranmış PDF tabloları OCR olmadan okunamaz. Excel Online, Google E-Tablolar ve LibreOffice için özel motor yoktur.

**Yayın öncesi:** DLL'lerin orijinal kaynak kodları yüklenen ZIP içinde bulunmadığından ayrıca eklenmelidir. Lisans kararı hak sahibi tarafından verilmelidir.


DLL kaynak kodları `native/` klasörüne eklendi; `native/README.md` dosyasında derleme talimatları bulunur. Proje lisansı henüz seçilmedi.
